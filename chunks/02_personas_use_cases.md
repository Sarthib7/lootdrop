# 02 — Personas and Use Cases

## Personas

- Community admin / guild leader: wants simple rewards and audit logs.
- AI agent: proposes or creates rewards based on events.
- Recipient / player / contributor: wants useful reward choice.
- Sponsor / partner: wants campaign accountability.
- Bitrefill: wants new repeatable demand and product discovery.

## Layer 1 use cases

```txt
Gaming MVP reward
Discord moderator reward
Hackathon micro-prize
Open-source bug bounty
DAO contributor reward
```

## Layer 2 use cases

```txt
Creator community rewards
Esports tournament rewards
Beta tester rewards
Student/coding club challenge rewards
Referral campaign rewards
```

## Layer 3 use cases

```txt
Employee recognition
Customer incentives
Support compensation
Influencer/community campaigns
```

Start with Layer 1. Mention Layers 2 and 3 as roadmap only.
